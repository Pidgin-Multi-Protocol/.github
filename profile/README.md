# Pidgin - Multi-Protocol Messenger with Contact List and Chat Window

## About Pidgin

Pidgin is a multi-protocol messenger. Pidgin Multi Protocol is the idea: several networks, one client. Pidgin Contact List is the roster. Pidgin Chat Window is the thread. A Pidgin Protocol Plugin is extra protocol support. Pidgin Status Message is available / away text you set.

Add only accounts you own. Keep Pidgin Contact List as people you already message. Use Pidgin Chat Window for 1:1 or a named room. Enable a Pidgin Protocol Plugin only for a network you actually use. Set Pidgin Status Message honestly for on-call. Pidgin Multi Protocol is not a reason to join every public room.

Pidgin Multi Protocol, Pidgin Contact List, Pidgin Chat Window, Pidgin Protocol Plugin, and Pidgin Status Message exist to talk on accounts you already have.

## Key Features of Pidgin

- **Multi protocol as the point** – Pidgin Multi Protocol is several networks in one process. Pidgin Contact List merges them if you let it; group by account if identity matters. Pidgin Chat Window must show which account is sending. A Pidgin Protocol Plugin is how a rare network appears. Pidgin Status Message can differ per account if you set that.
- **Contact list as the roster** – Pidgin Contact List is known people and rooms. Pidgin Chat Window opens from here. Pidgin Multi Protocol still has separate logins. A Pidgin Protocol Plugin should not auto-add strangers. Pidgin Status Message does not replace a name you recognize.
- **Chat window as the thread** – Pidgin Chat Window is 1:1 or a named chat. Watch the From account. Pidgin Contact List is how you got there. Pidgin Multi Protocol is the wire. A Pidgin Protocol Plugin may change formatting. Pidgin Status Message is not the conversation.
- **Protocol plugin as a gap** – A Pidgin Protocol Plugin is for a network the core does not ship, or an extra. Enable one. Test. Pidgin Multi Protocol should still start. Pidgin Contact List should still fill. Pidgin Chat Window should still send. Pidgin Status Message should still set. Disable the rest.
- **Status message as presence** – Pidgin Status Message is “on call” or “in a change.” Set it on the accounts that matter. Pidgin Multi Protocol can broadcast it. Pidgin Contact List shows you to others. Pidgin Chat Window is still where work happens. A Pidgin Protocol Plugin should not override it silently.

## Quick Start with Pidgin

1. **One account** – Add one login. Pidgin Multi Protocol is now one network. Ignore extra Pidgin Protocol Plugin. Open Pidgin Contact List. Send in Pidgin Chat Window. Set a simple Pidgin Status Message.
2. **Second network only if needed** – Another account. Pidgin Multi Protocol now two. Group Pidgin Contact List. Watch Pidgin Chat Window From. Still one Pidgin Protocol Plugin at most. Pidgin Status Message per account if on-call differs.
3. **Plugin only for a gap** – Enable one Pidgin Protocol Plugin. Test send in Pidgin Chat Window. Confirm Pidgin Contact List. Confirm Pidgin Multi Protocol still signs in. Confirm Pidgin Status Message. Disable if unused.
4. **Roster hygiene** – Remove dead names from Pidgin Contact List. Recheck Pidgin Chat Window logs per policy. Recheck accounts under Pidgin Multi Protocol. Recheck Pidgin Protocol Plugin after an update. Recheck Pidgin Status Message defaults.
5. **Review** – Personal and work still split. Pidgin Multi Protocol only live networks. Pidgin Contact List auditable. Pidgin Chat Window not a dump. Pidgin Protocol Plugin still few. Pidgin Status Message still honest.
